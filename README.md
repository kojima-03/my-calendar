# マイカレンダー

予定・タスク・買い物リストを、ひとつのカレンダーで管理できる個人用のWebアプリです。
PC でもスマホでも使え、ホーム画面に追加してアプリのように起動できます（PWA対応）。

**公開URL：** https://kojima-03.github.io/my-calendar/

## 作った理由

既存のカレンダーアプリは、「予定」と「この日までにやること（タスク）」が別々のアプリに分かれていることが多く、
1か所で見渡せるものを自分用に作りたいと考えました。
職業訓練で学んでいる HTML / CSS / JavaScript の実践として、企画から公開まで一人で行っています。

## 主な機能

### 予定
- 日付、開始時間、終了時間、場所、メモを登録できます
- 場所をタップすると、地図アプリ（Google マップ）で検索できます
- リマインダー（開始時刻に通知、10分前、1時間前、1日前）を設定できます

### タスク
- 「この日までにやること」を期限日つきで登録します
- 月表示のカレンダー上にチェックボックスを表示し、チェックすると完了扱いになってカレンダーから消えます
- 完了したタスクは「完了済み」一覧で確認でき、チェックを外せば元に戻せます
- 期限を過ぎた未完了のタスクは、一覧に赤字で残ります

### リスト（買い物リストのような使い方）
- 複数の項目を持つリマインダーを作れます（例：買い物リスト）
- 開くとポップアップで項目が表示され、その場でチェック・追加・削除ができます
- 日付を入れるとカレンダーにも進み具合（例：📋 買い物 1/3）が表示されます
- 日付なしで、いつでも見られる常設リストとしても使えます

### 使いやすさ
- 日付をタップすると、その日の一覧がポップアップで開き、そこから追加できます
- 右下の「＋」ボタンから、いつでも新規作成の入力欄を開けます
- 登録済みの予定・タスク・リストは、後から編集・削除できます
- ページの背景色と、日付マスの色を別々に変更できます
- スマホ・PC のどちらの画面幅にも対応したレスポンシブデザインです
- ライト／ダークの端末設定に合わせて、表示が自動で切り替わります

### PWA（アプリとして使う）
- スマホ・PC のホーム画面に追加して、アプリのように全画面で起動できます
- Service Worker により、一度開いたあとはオフラインでも画面を開けます

## 使っている技術

| 分野 | 内容 |
| --- | --- |
| 画面 | HTML / CSS（Grid・Flexbox・CSS 変数・メディアクエリ） |
| 動作 | JavaScript（ライブラリやフレームワークは使わず、素の JavaScript で実装） |
| データ保存 | ブラウザの localStorage |
| アプリ化 | PWA（Web App Manifest、Service Worker） |
| 通知 | Notification API |
| 公開 | GitHub Pages |

## 工夫した点

- **ひとつの画面で全体を見渡せる**：予定とタスクを同じ月表示に載せ、完了したタスクは自動で消えるようにして、カレンダーがごちゃつかないようにしました。
- **入力の手間を減らす**：日付のタップや「＋」ボタンからすぐ入力でき、入力欄はポップアップで開くので、画面をスクロールせずに操作できます。
- **スマホでの使いやすさ**：入力欄は画面の下から出る形にし、ボタンは指で押しやすい大きさにしました。
- **フレームワークに頼らない実装**：状態の管理、画面の描画、イベント処理をすべて JavaScript で書き、仕組みを理解しながら作りました。

## 使い方

1. 公開URLをブラウザで開きます
2. 右下の「＋」ボタン、または日付のタップから、予定・タスク・リストを追加します
3. スマホの場合は、ブラウザのメニューから「ホーム画面に追加」を選ぶと、アプリのように使えます
   - iPhone：Safari の共有ボタン →「ホーム画面に追加」
   - Android：Chrome のメニュー →「アプリをインストール」または「ホーム画面に追加」

### 手元で動かす場合

ビルドの作業は不要です。このリポジトリを取得して、`index.html` をブラウザで開くだけで動きます。
（Service Worker を動かすには、`python -m http.server` などで簡易サーバーを立てて開いてください）

## 現在の制限

- データは、使っているブラウザの中（localStorage）に保存されます。PC とスマホは、まだ同期されません。
- 通知は、アプリやページを開いている間だけ動作します。閉じている間は届きません。

## 今後の予定

- PC とスマホでデータを同期する（サーバー側で保存する仕組みを検討中。Java の Spring Boot と SQL のデータベースで作ることを考えています）
- アプリを閉じていても届くプッシュ通知
- 繰り返し予定、タスクの優先度や色分け
